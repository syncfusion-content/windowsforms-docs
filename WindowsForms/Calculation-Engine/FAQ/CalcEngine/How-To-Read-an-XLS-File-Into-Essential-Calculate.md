# How To Read an XLS File Into Essential Calculate?

To get Essential Calculate to work with an XLS file, use Essential XlsIO. Essential XlsIO is a library that exposes Excel-Like Automation APIs without any dependence upon Excel. It has the ability to Read / Write XLS files.

For details, see [Working with XlsIO](https://help.syncfusion.com/windowsforms/calculate/working-with-xlsio).
