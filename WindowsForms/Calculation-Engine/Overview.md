# Windows Forms Calculation Engine (Calculate)

Essential Calculate is a native .NET class library that enables parsing and computing expressions and formulas with 400+ predefined functions. It can be used in any .NET environment, including C#, VB.NET and managed C++ code.
It is a non-UI component that provides a full-fledged object model that facilitates formula calculation support without dependency on Microsoft Office COM libraries.

The range of calculations includes simple algebraic expressions such as `(1.2^3-1)/8`, formulas using intrinsic functions like `4 * SQRT(EXP(8.4))`, and formulas that rely on variables defined through controls on a form, for example `COS([TextBox1] * PI()/180)`. It also supports spreadsheet-like syntax with cell references such as `SUM(A2:B14)`.

The following are the key features of Essential Calculate:

* Extensive calculation support can be added to the user's own business objects.
* It comes with a function library of more than 400 built-in functions.
* It provides support to named ranges, dynamic references, array formulas and formula dependencies.
* Supports cross sheet references (can work with multiple sheets).
* Supports custom functions with any number of optional arguments.
* Culture-sensitive decimal separator and argument separator.
* It can be used in conjunction with Essential XlsIO to fully load, manipulate, and compute Excel spreadsheets.
* It enables you to perform calculations independent of Microsoft Excel.
