# About Syncfusion® WinForms Context Menu Strip

WinForms Context Menu Strip is a group of frequently used commands or menu items that can be accessed by right-clicking the target control. For example, **Cut**, **Copy**, and **Paste** — frequently used commands — are grouped and accessed through a simple right-click option.

For a hands-on walkthrough of creating and configuring the control, see [Getting Started](getting-started).

## Key Features

* [**ToolStripItems**](toolstripitem-types) - ToolStripItems like MenuItem, TextBox, ComboBox and Separator can be added as menu items to the WinForms Context Menu Strip control.
* [**Render Mode**](render-mode) - Represents the painting style applied to the control.
* [**Checked/Unchecked**](checkedstate-of-menu-items) - Indicates whether a check mark appears before the text of the selected menu item.
* [**Enable/Disable**](disable-menu-items) - Menu items can be enabled or disabled based on user requirement.
* [**Auto Close**](auto-close) - Specifies whether the WinForms Context Menu Strip should close for any user actions at runtime.
* [**Customization**](appearance-customization) - Customize the Text, Image Display, Background Color, Font, Foreground Color, and so on.
* [**Tooltip**](tooltip) - Provides options to set a tooltip for each menu item.
* [**Themes**](themes) - Supports a set of visual styles to customize the look and feel of the WinForms Context Menu Strip control.
* [**RTL**](rtl) - Display the content from right to left.
