# How to activate text in WinForms Currency TextBox

When the control is set to disabled, the user cannot make any changes to it. But you can make the text active by setting the [DrawActiveWhenDisabled](https://help.syncfusion.com/cr/windowsforms/Syncfusion.Windows.Forms.Tools.TextBoxExt.html#Syncfusion_Windows_Forms_Tools_TextBoxExt_DrawActiveWhenDisabled) property to `True`.
