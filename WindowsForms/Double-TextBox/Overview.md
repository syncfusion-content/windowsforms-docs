# About Syncfusion® WinForms Double TextBox Control

The WinForms Double TextBox is a text box-derived control that can display double data type values.

It is derived from the Windows Forms Framework `TextBox` control. It supports display and collection of double values, handles user keyboard input and double formatting, and uses the globalization features of the .NET platform to provide locale-specific formatting.
