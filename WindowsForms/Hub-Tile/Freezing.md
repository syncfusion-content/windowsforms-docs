# Freezing in Windows Forms Hub Tile 

The Notification and animation of a Hub Tile can be frozen by enabling the [IsFrozen](https://help.syncfusion.com/cr/windowsforms/Syncfusion.Windows.Forms.Tools.HubTile.html#Syncfusion_Windows_Forms_Tools_HubTile_IsFrozen) property.

{% tabs %}

{% highlight C# %}  

this.HubTile1.IsFrozen = true;

{% endhighlight %}

{% highlight VB %} 

Me.HubTile1.IsFrozen = True

{% endhighlight %}

{% endtabs %}
