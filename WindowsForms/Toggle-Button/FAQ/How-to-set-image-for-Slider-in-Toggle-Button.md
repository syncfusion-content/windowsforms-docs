# How to Set Image for Slider in WinForms Toggle Button

You can set the image through the `Image` property. The following code example illustrates the same.

{% tabs %}
{% highlight c# %}

this.toggleButton1.Slider.Image = global::ToggleButtonDemo2010.Properties.Resources.big_tick;

{% endhighlight %}

{% highlight vb %}

Me.toggleButton1.Slider.Image = Global.ToggleButtonDemo2010.Properties.Resources.big_tick

{% endhighlight %}
{% endtabs %}
