# About Syncfusion® WinForms Toggle Button Control

WinForms Toggle Button control for Windows Forms allows you to toggle between two states (Active and Inactive) that are opposite to each other in terms of behavior.

![Overview of Syncfusion Toggle Button](Overview_images/Overview_img1.jpeg)


## Key features

* Configurable Toggle States: Two states with contrasting behavior can be configured as required like IN/OUT, ON/OFF, etc.

* Display Mode: Supports displaying either text or image over buttons to represent the states.

* Custom Renderer: Allows the end-user to apply custom styles at application level.
