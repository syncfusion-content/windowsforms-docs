# About Syncfusion® WinForms Watermark Text Provider Control

Syncfusion introduces a [WinForms Watermark Text Provider](https://help.syncfusion.com/cr/windowsforms/Syncfusion.Windows.Forms.BannerTextProvider.html) class that allows to display watermark in the Editor controls. It can be used as an information when the mapped edit control contains empty content.

![Overview of BannerTextProvider](Overview_images/overview.png) 

## Key features

The [WinForms Watermark Text Provider](https://help.syncfusion.com/cr/windowsforms/Syncfusion.Windows.Forms.BannerTextProvider.html) contains the following features:

* **Text Mode** - Allows you to control visibility of the banner text using FocusMode and EditMode.

* **Text color** - Allows you to set color to the WinForms Watermark Text in the WinForms Watermark Text Provider control.
