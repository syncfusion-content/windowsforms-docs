# About Syncfusion® Windows Forms XPToolBar Control

The XPToolBar control is a Microsoft Visual Studio-inspired standalone toolbar control that can be used to load shortcut options and place them conveniently anywhere within the application for better access.

## Key Features

* **BarItem types** - [BarItem](https://help.syncfusion.com/windowsforms/xptoolbar/baritem-types), ParentBarItem, DropDownBarItem, ComboBoxBarItem, ListBarItem, StaticBarItem, MdiListBarItem, ToolbarListBarItem, TextBoxBarItem and Separator can be added as a BarItem of the XPToolbar.

* **Multiple toolbar** - We can add different levels of toolbar consecutively. For more details, refer to the [Multiple Toolbar](https://help.syncfusion.com/windowsforms/xptoolbar/multiple-toolbar) documentation.

* **Docking** - We can position the control at top, bottom, left and right. For more details, refer to the [Docking](https://help.syncfusion.com/windowsforms/xptoolbar/docking) documentation.

* **Chevron/Overflow Button** - View other options that may not readily visible at the initial view. For more details, refer to the [Chevron and Overflow Button](https://help.syncfusion.com/windowsforms/xptoolbar/chevron-overflow-button) documentation.

* **Customization** - We can customize the Text, Background Color, Font, Foreground Color, etc. For more details, refer to the [Appearance](https://help.syncfusion.com/windowsforms/xptoolbar/appearance-customization) documentation.

* **Tooltip** - Provides options to set tooltip for each BarItem. For more details, refer to the [Tooltip](https://help.syncfusion.com/windowsforms/xptoolbar/tooltip) documentation.

* **Keyboard shortcuts** - Provides options for accessing bar items through keyboard shortcuts and custom shortcut display text. For more details, refer to the [Keyboard Shortcuts](https://help.syncfusion.com/windowsforms/xptoolbar/keyboard-shortcuts) documentation.

* **Themes** - Supports set of visual styles to customize the look and feel of XPToolbar control. For more details, refer to the [Themes](https://help.syncfusion.com/windowsforms/xptoolbar/themes) documentation.

* **RTL** - Display the content from right to left. For more details, refer to the [RTL](https://help.syncfusion.com/windowsforms/xptoolbar/rtl) documentation.

* **Localization** - Provides options to localize the text in the XPToolBar control. For more details, refer to the [Localization](https://help.syncfusion.com/windowsforms/xptoolbar/localization) documentation.
