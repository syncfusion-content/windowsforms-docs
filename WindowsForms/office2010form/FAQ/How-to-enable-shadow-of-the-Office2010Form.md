# How to Enable Shadow in Windows Forms Office2010Form

Shadow of the WinForms Office2010Form can be enabled or disabled using the [DropShadow](https://help.syncfusion.com/cr/windowsforms/Syncfusion.Windows.Forms.Office2010Form.html#Syncfusion_Windows_Forms_Office2010Form_DropShadow) property.

{% tabs %}

{% highlight C# %}

this.DropShadow = false;

{% endhighlight %}

{% highlight VB %}

 Me.DropShadow = false 
 
{% endhighlight %}

{% endtabs %}
